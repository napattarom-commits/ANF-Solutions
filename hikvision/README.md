# HIKVISION BY ANFSOLUTIONS — Sales Site

A standalone fire-safety sales mini-site for HIKVISION products, distributed and integrated by ANFSOLUTIONS in Thailand.

## Pages

- `index.html` — Landing page with hero, product menu and CTA
- `products.html` — Full product catalogue (Conventional, Fusion Camera, LoRa, Standalone, Cable)
- `hikvision.html` — Dedicated HIKVISION brand showcase
- `contact.html` — Inquiry form and contact info

## Structure

```
hikvision/
├── index.html
├── products.html
├── hikvision.html
├── contact.html
├── css/
│   └── styles.css
└── assets/
    └── *.jpg
```

## Tech

Static HTML5 + CSS3 — no build step. Open `index.html` in a browser or deploy to any static host (GitHub Pages, Netlify, Vercel, S3).
